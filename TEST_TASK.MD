# Тестовое задание

## Написать веб-приложение, работающее с СУБД и хранящее в ней данные

## Стек технологий

СУБД - Postgresql,
бэкенд - Java + Spring Boot,
фронтенд - Vuejs 3.x + Pinia + Vite + какой-либо UI-фреймворк для отрисовки компонентов страницы (например Tdesign, ElementUI, PrimeVue, Quasar).
Предметная область - автостоянка. Приложение должно предоставлять визуальный интерфейс пользователя - администратора автостоянки.

## Требования

приложение должно содержать 2 web-страницы;
1-я страница: учет мест, автомобилей, владельцев (добавление, редактирование и удаление через интерфейс, поиск - автомобилей по номеру, владельца по ФИО);
2-я страница: бронирование/освобождение и оплата места (поиск брони по номеру авто и по ФИО владельца, оплата - простой признак - true/false в карточке брони);
Сильно углубляться в детали не нужно, достаточно продемонстрировать умение спроектировать такую систему в общих чертах и применить для реализации требуемый стек технологий.

## Шаги реализации

1. Установить СУБД, создать БД и структуру таблиц под задачу.
2. Для реализации бэкенда создать приложение Spring Boot. Взаимодействие с БД выполнить с использованием jdbcTemplate с маппингом данных на соответсвтующие объекты в Java. Для подключения сторонних Java-библиотек и сборки приложения желательно использовать Maven.
3. Для реализации фронтенда создать приложение Vuejs (желательно использовать Composition API, приветствуется использование TypeScript) с билдером Vite, хранилищем Pinia и выбранным UI-фреймворком.
4. С использованием вышеперечисленных средств создать несколько страниц, через которые пользователь приложения будет выполнять перечисленные в п.1 функции.
Результат работы для предварительного просмотра предоставлять в виде исходного кода проекта для фронтенда и бэкенда отдельными архивами или ссылками на github, структуру БД в виде дампа (желательно sql-файла).
